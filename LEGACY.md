# Recovered pSIONIUM code

The original `~/psionium` and `~/pSIONIUM_2.0` folders were lost without a backup. This branch holds everything VS Code's local history still had, recovered on 2026-10-16.

- `psionium/`: Python backend, modules and systems, shells, Flutter app (`dock/`), web frontend, and an unrelated Django app (`codegpt/`).
- `pSIONIUM_2.0/`: Rust workspace (crypto engine, network resilience, AI threat detection, autonomous response, UI).
- `_all_versions/`: every saved version of every file; the suffix is the save time.
- `RECOVERY_REPORT.md`: the list of files, version counts and latest save dates.

Files that were never opened and saved in VS Code could not be recovered. An OpenAI API key and a Django secret key found in some versions were replaced with `REDACTED`.
